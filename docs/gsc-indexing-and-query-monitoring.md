# GSC Indexing and Query Monitoring

YieldLens UK is now in observe, bug-fix and signal-tuning mode. This note turns Google Search Console data into a short list of actions, so search demand decides what gets tuned next.

## 1. Purpose

- This doc exists to stop random SEO work.
- GSC should decide what gets tuned next.
- Page expansion is paused until the current pages show which clusters Google understands.
- Wrong-intent rental valuation traffic should not drive strategy.
- The goal is to improve the pages already on the site before adding anything new.

## 3. Query clusters to monitor

### Commercial lease viability

Target pages:
- `/commercial-lease-viability-check`
- `/restaurant-lease-viability-check`
- `/salon-lease-viability-check`
- `/compare`

Queries:
- commercial lease viability check
- lease viability check
- restaurant lease viability check
- salon lease viability check
- commercial lease affordability check

Good signal:
- relevant pages start earning impressions
- average position improves from weak double-digit or 70-plus territory
- clicks begin to appear on the intended commercial page

Bad signal:
- traffic lands on a residential or generic valuation page
- the wrong page ranks for the query
- impressions stay flat while the query remains far from page 1

If impressions rise:
- improve the title, meta description, quick answer, and internal links on the page already ranking.

If position improves:
- keep the page structure stable and strengthen the answer block rather than rewriting the whole page.

If clicks happen:
- check CTA placement and whether the sample file or free check bridge is clear enough.

- `/how-much-rent-can-a-cafe-afford`
- `/how-much-rent-can-a-shop-afford`
- `/how-much-rent-can-a-takeaway-afford`
- `/how-much-rent-can-a-barber-shop-afford`

Queries:
- commercial rent affordability calculator
- commercial rent burden calculator
- how much rent can a cafe afford
- how much rent can a shop afford
- how much rent can a takeaway afford
- how much rent can a barber shop afford

Good signal:
- the business-type pages start showing impressions
- the commercial calculator becomes the main ranking page for generic rent affordability terms
- the query intent stays commercial rather than residential

Bad signal:
- rental valuation terms dominate
- the residential comparison page gets the impression share
- clicks do not appear on the intended commercial page

If impressions rise:
- improve the page that already has the signal. Do not create another near-duplicate page.

If position improves:
- tighten the answer block and ensure the example is clear.

If clicks happen:
- check whether the free commercial check CTA and sample file bridge are obvious enough.

### Sample and paid intent

- `/report`

Good signal:
- sample file queries bring clicks
- the paid-file explanation page gets impressions for decision memo style terms

Bad signal:
- the pages are being read as generic report templates
- clicks do not move into checkout or paid file open

If impressions rise:
- strengthen the sample proof and the free to paid bridge.

If position improves:
- keep the current structure and improve the clarity of what the paid file contains.

If clicks happen:
- review whether the paid-file CTA is clear and whether the sample page is persuasive enough.

### Wrong intent and noise

Queries to watch but not chase:
- rent valuation
- rental valuation
- online rental valuation
- free rental valuation
- instant rental valuation
- rental property valuation

Good signal:
- these terms decline in share or stay isolated on bridge pages.

Bad signal:
- they dominate impressions and start pulling attention away from the commercial pages.

If impressions rise:
- do not build more pages around them.

If position improves:
- only use bridge wording that points people back to commercial intent.

If clicks happen:
- do not expand into valuation content unless the product strategy changes.

## 4. 3-day checks

At day 3, check:

- key pages are indexed or indexing has been requested
- sitemap is reachable
- robots.txt is reachable
- new pages are appearing in GSC, if any
- there is no obvious crawl or indexing break

Do not react to ranking volatility at this stage.

## 5. 7-day checks

At day 7, check:

- impressions by page
- queries by page
- whether restaurant, salon, and cafe pages still show the best early commercial signal
- whether `/compare` gets impressions
- whether `/sample-commercial-viability-file` gets impressions
- whether wrong-intent rental valuation terms still dominate
- whether any page has average position better than 30
- whether any page has impressions but zero clicks

If a page has impressions but no clicks, it usually needs clearer first-screen copy or a stronger CTA bridge.

## 6. 14-day checks

At day 14, use these decision rules:

If a page has impressions and position better than 30 but zero clicks:
- improve the title or meta description
- improve the above-the-fold clarity
- add a stronger CTA if it fits naturally
- do not rewrite the entire page

If a page has position 5 to 15 and impressions:
- improve the answer block, worked example, FAQs, and internal links
- check AI Overview and source-panel visibility
- do not add a competing page for the same intent

If wrong-intent rental valuation traffic dominates:
- do not chase those queries
- keep bridge wording clear
- route users toward commercial intent where appropriate

If a business-type page gets impressions:
- tune that page before building more business-type pages

If before-signing support pages get impressions:
- improve the hub page and internal links first

## 7. 28-day checks

At day 28, choose:

- top 3 pages by relevant impressions
- top 3 pages by best average position
- pages with impressions but weak clicks

Then compare GSC with admin funnel events.

Decision outputs:
- tune existing page
- improve title/meta
- improve answer block
- add internal link
- improve sample or CTA bridge
- no action
- only build a new page if there is repeated query signal and no existing page fits

## 9. Page tuning rules

Safe tuning actions:

- improve the page title if it is unclear
- improve the meta description if it is weak
- improve the quick answer block
- remove repeated or filler content
- add one useful worked example
- add internal links to the free check, sample file, compare, or a related guide
- improve CTA placement
- tighten FAQ answers
- clarify what YieldLens does and does not do

Do not:

- add fabricated reviews
- add fabricated author credentials
- keyword stuff
- create thin pages
- chase unrelated rental valuation terms
- create a page for every tiny query before the current pages are validated

## 10. Admin and GSC comparison

Use GSC and admin data together:

- GSC impressions and clicks show search demand
- admin events show product demand
- a page with impressions but no check starts needs CTA or journey work
- a page with no impressions is not yet a product problem
- a page with check starts but no paid CTA clicks needs results and paid bridge review
- a page with checkout starts but no payments needs trust, price, or payment review

## 11. Weekly manual routine

Run this routine once a week:

1. Export GSC queries.
2. Export GSC pages.
3. Record the top relevant pages.
4. Record noisy wrong-intent pages.
5. Record admin funnel events.
6. Record any AI Overview appearances.
7. Choose no more than 3 actions for the week.
8. Avoid adding new pages unless the query evidence clearly justifies it.
