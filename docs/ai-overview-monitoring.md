# AI Overview Monitoring

## Purpose
YieldLens has already appeared as a cited source in a Google AI Overview for a restaurant lease viability query. The goal is to track whether that repeats across commercial lease viability, rent affordability, and business-type queries.

## Important note
There is no guaranteed way to force AI Overview inclusion. The strategy is to make pages clear, answer-like, specific, structured, and useful enough to be cited.

## Queries to test weekly

### Core
- restaurant lease viability check
- commercial lease viability check
- commercial rent affordability calculator
- commercial rent burden calculator
- commercial lease checklist before signing

### Business type
- how much rent can a cafe afford
- how much rent can a shop afford
- salon lease viability check
- restaurant lease viability
- cafe rent affordability
- shop rent affordability

### Risk specific
- commercial lease service charge before signing
- commercial lease deposit before signing
- commercial break clause before signing
- commercial personal guarantee commercial lease
- commercial heads of terms before signing

## What to record

For each query, record:
- date checked
- browser or location if relevant
- AI Overview present: yes or no
- YieldLens cited in AI Overview: yes or no
- YieldLens in source panel: yes or no
- YieldLens organic position if visible
- ranking URL
- wording Google pulled from YieldLens
- competitors cited
- screenshot saved: yes or no
- action needed

## Scoring

Use a simple score:
- 0 = not visible
- 1 = organic only below top 10
- 2 = organic top 10
- 3 = source panel citation
- 4 = directly cited in AI Overview text
- 5 = cited in AI Overview and organic top 10

## Action rules

If YieldLens is cited:
- do not rewrite the page immediately
- preserve the answer structure that worked
- improve only if there is an obvious gap

If YieldLens is not cited but ranks top 20:
- improve quick answer
- strengthen key checks
- add concise definitions
- improve related internal links

If YieldLens is not visible:
- wait for indexing if the page is new
- check GSC impressions
- only create new content if multiple related queries justify it

## Screenshot storage

Save screenshots in a local folder outside the repo, for example:
`~/Desktop/yieldlens-serp-screenshots`

Do not commit screenshots unless intentionally needed.

## Review cadence

- Weekly for manual AI Overview checks
- Every 14 days for GSC query movement
- Every 28 days before deciding whether to create more pages

## No-spend strategy

Current strategy:

- no manual outreach

- use GSC query rescue
- build into query patterns Google already ranks
- optimise answer blocks for AI Overview and source-panel capture
