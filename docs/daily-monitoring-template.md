## 9. Decision Rules

- If relevant impressions rise but clicks stay zero: improve title, meta description, and first-screen clarity.
- If clicks happen but no check starts: improve CTA placement and product journey.
- If checks start but few submissions: reduce form friction.
- If results happen but no paid CTA clicks: improve sample-file proof and paid-file bridge.
- If checkout starts but no payments: review trust, price, checkout copy, and sample-file clarity.
- If one unaffiliated user pays: inspect source path and journey, then improve the same funnel first. Do not immediately build features.

## 11. Stop Rules

Stop building if:

- no route is broken
- no checkout/access issue exists
- no public trust issue exists
- GSC has not produced enough new data
- admin has no meaningful user activity yet

Only continue if:

- a route fails
- a payment/access path breaks
- source pages get clicks but no check starts
- checks start but form submissions fail
- checkout starts but payments fail
- a page with real GSC signal needs tuning
