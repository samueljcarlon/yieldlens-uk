# SEO Query Rescue Workflow

This note is for internal use. It turns Google Search Console data into a short list of page improvements for YieldLens UK.

## 1. Current problem

YieldLens can already earn impressions for relevant commercial queries, but some of those queries sit at weak average positions.

The aim is to move existing impression queries toward page 1 or page 2 by improving the pages already on the site.

Do not judge success by clicks alone if average position is still around 70 or worse. At that point, the main signal is whether the query is moving up and whether the page is becoming the right match.

## 2. Export needed from GSC

Use Google Search Console:

1. Open `Performance`.
2. Use `Search results`.
3. Set the date range to `Last 28 days`.
4. Export:
   - Queries
   - Pages
   - Query/page combinations if the export is available

If possible, keep the same export window for each review cycle so movement is easier to compare.

## 3. Priority scoring

Prioritise queries with:

- impressions above 20
- average position between 20 and 90
- clear commercial intent
- a matching page already exists
- low or zero clicks

Avoid prioritising:

- purely residential valuation queries unless they can be cleanly bridged
- template or download queries
- legal-advice queries
- student, job, or definition queries
- irrelevant residential traffic

## 4. Query buckets

Sort queries into these buckets:

- commercial lease viability
- commercial rent affordability
- commercial rent burden
- commercial lease checklist before signing
- lease costs before signing
- rent deposit, service charge, business rates
- break clause, rent review, lease length
- personal guarantee, heads of terms
- rental valuation noise

These buckets help decide whether to improve an existing page, strengthen internal links, or ignore the query.

## 5. Action rules

For each query/page pair:

- If the query and page match, improve the title, description, H1, intro, FAQ, and internal links.
- If the query is ranking on the wrong page, add internal links from the ranking page to the better target page.
- If the query is irrelevant, do not chase it.
- If the query is residential but high impression, consider whether the existing rental valuation comparison page should handle it.
- Do not create a new page unless at least 3 to 5 related queries justify it.

## 6. Fields to track

Track each item in a simple table:

| query | impressions | clicks | CTR | position | ranking page | intent bucket | action | status | check date | next review date |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |

Keep one row per query/page pair where possible.

## 7. 72-hour and 14-day review

Use short windows for different jobs:

- 48 to 72 hours is for indexing and crawl checks only.
- 14 days is the better minimum window for movement in impressions and rankings.
- 28 days is better for deciding whether a new page is actually needed.

Do not overreact to one or two days of data.

## 8. No-spend traffic plan

Current plan:

- no paid search until budget allows
- no manual outreach
- no Reddit
- focus on GSC-led SEO, free indexing surfaces, owned profile links, and product-led conversion

Keep the work steady and based on observed query movement.
